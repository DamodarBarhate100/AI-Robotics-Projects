# AI Robotics Projects

A collection of robotics, embedded systems, and machine learning projects documenting my journey toward building intelligent autonomous robots.

This repository combines robotics engineering, embedded programming, computer vision, machine learning, and ROS 2 to develop robots that can perceive, reason, and interact with the real world.

---

## Vision

The long-term objective of this repository is to build increasingly capable autonomous robotic systems by combining:

- Artificial Intelligence
- Machine Learning
- Robotics
- Embedded Systems
- Sensor Fusion
- Computer Vision
- ROS 2
- Mechanical Design

Each project represents a milestone in developing practical robotics skills while following professional software engineering and documentation practices.

---

# Projects

## Open Legged Robotic Platform (JARVIS)

An intelligent quadruped robotic platform being developed from the ground up.

Current development includes:

- Hardware architecture
- Mechanical design
- Power distribution
- Kinematics
- Balance and stability
- Motion control
- ROS 2 integration
- AI-assisted locomotion

Current Version:

**v0.1 – Hardware & Foundation**

---

## Multimodal Sensor Fusion for Terrain Classification

An edge AI rover that classifies terrain using multiple onboard sensors.

Technologies:

- ESP32
- Sensor Fusion
- Machine Learning
- Softmax Regression
- Embedded AI

---

## Intelligent Obstacle Detection and Ranging System

A foundational embedded robotics project demonstrating distance sensing and obstacle detection using ultrasonic sensors.

Technologies:

- ESP32
- HC-SR04
- Embedded C++
- Arduino Framework
